AI Agent · Competitive Intelligence

Competitive Intelligence Agent

An agent that tracks peer agencies on a set framework and flags unusual moves.

Built at Weber Shandwick. Peer names and findings are not shown on this page.

01

The problem

Keeping up with how peer agencies are doing meant checking many places by hand: financials, industry rankings, awards, and more.

The information was scattered and formatted differently in each source.

02

The framework

I defined which peers to track, based on how similar they are to Weber Shandwick, and what to evaluate for each one.

The same framework is applied to every peer so the results can be compared.

04

The steps

  1. Pull information from about 10 sources, including financial information, PR ranking sites, and awards.

  2. Compile it into structured documents, with the same fields for every peer.

  3. Store the documents in a database.

  4. Use NotebookLM to read, sort, clean, and extract from the long, unstructured documents.

  5. Load the cleaned material into an agent.

  6. Every week, update the database, flag anything unusual, and email me a link to the update.

05

Two ways to use the data

Ask NotebookLM directly

Upload everything and ask questions. It is fast and good at reading very long documents, but it only answers when I ask.

Use the agent

It has the same material plus instructions on what to watch for. It alerts me when a peer does something unusual, so I don't have to ask.

06

Sample alert

Fictional example. Real findings are not shown.

Alert: Agency X moved up four places in a ranking since last week. That is a bigger jump than its usual movement. Worth a look before the next update.

07

Limits

Public sources can be incomplete or out of date, so a person checks anything important before it is used.

The agent flags changes. It does not decide what they mean.
