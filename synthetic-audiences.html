AI Agents · Message Testing

Synthetic Audiences

Persona agents that respond like a specific audience, built to test messaging.

Built at Weber Shandwick for multiple clients. Client details are not shared on this page.

01

The ask

Teams wanted a faster way to test messaging against specific audiences.

The request was to build personas that respond and behave like the real persona, so a strategist could ask how a message would land and get a useful reaction.

02

The data

Demographic, psychographic, and survey data from audience tools like StatSocial and Audience Console, plus research briefs and strategy briefs.

The material was long, unstructured, and formatted differently from client to client.

03

The process

  1. Clean up and structure the data.

  2. Use NotebookLM to read and organize the long, unstructured briefs.

  3. Create a standardized template that defines what each persona needs.

  4. Check data quality, fill gaps, and keep formats consistent across every persona.

  5. Turn each persona into a standardized document that goes into the agent.

  6. Write guidance prompts for the agent: guardrails, behaviors, how it should respond, what it should be aware of, and how to read each file based on what the user is asking.

    Rules the agent follows

    • Stay inside the persona data. If the data doesn't cover something, say so and don't guess.
    • Read the files based on the context of the question. Don't assume details that aren't there.
    • If something is unclear, ask. Keep follow-ups to a minimum, one short question at a time.

04

What a persona file includes

A simplified view of the template.

  • Demographics
  • Psychographics and values
  • Media and platform habits
  • Purchase behavior
  • Pain points and objections
  • Language and tone
  • Source and date of the data

06

Sample input and output

Fictional brand and persona, to show how it works.

Strategist

Test this headline with Maya: "Dinner, handled. Fresh ingredients, zero planning."

Maya

The "zero planning" part gets me. I work late a few nights a week and I'm tired of deciding what to eat. But "fresh" makes me skeptical, because every meal kit says that. I'd stop scrolling for something specific, like how long dinner takes or what a meal costs. I watch my grocery spending, so a price per meal would help.

Strategist

What does she think about the packaging?

Maya

My profile doesn't say how I feel about packaging, so I'd rather not guess. I can tell you how I shop and what I look at first, if that helps.

The second answer shows the guardrail. The agent says when the persona data doesn't cover a question.

07

Limits

A synthetic audience is a first read on how a message might land. It doesn't replace real audience research, and people review the output before it goes anywhere.
